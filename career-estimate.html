Оценка сроков и стоимости

Три идеи карьерного сайта Т-Банка: реализация в трёх уровнях бюджета

Документ содержит девять вариантов реализации: для каждой из трёх идей презентации рассчитаны уровни «Минимум» (до 4,5 млн ₽), «Средне» (до 6 млн ₽) и «Максимум» (до 8 млн ₽) с составом работ, сроками и сметой по статьям.

Дата: 7 сентября 2026. Все суммы без НДС. Работы выполняются под ключ: сценарии и контент, дизайн, арт-продакшен, разработка, тестирование, развёртывание и инфраструктура на период кампании. Расходы на LLM и генерацию изображений считаются отдельно (раздел 8). Сроки ориентировочные. Цифры без указания источника являются оценкой исполнителя.

2Принцип построения уровней

Три идеи различаются между собой контентным наполнением и способом подачи: игровой офис, расследование на рабочем столе, кинематографический пролёт. Внутри каждой идеи три уровня являются родственными реализациями одного замысла. Уровень «Минимум» содержит полный пользовательский сценарий от входа до перехода в вакансии; уровни «Средне» и «Максимум» наращивают степень проработки и качество исполнения, а не меняют подход.

Наращивание выполняется по четырём измерениям. Первое: объём контента, то есть число сцен, отделов, досье, файлов и историй. Второе: глубина интерактива, то есть число мини-игр, состояний сцен и реакций объектов. Третье: технология слоя сцены, где верхние уровни переходят от заранее отрендеренных изображений к real-time 3D и получают свободу камеры и перемещения. Четвёртое: сервисный контур для заказчика, то есть административный интерфейс, сохранение прогресса, ответы на свободные вопросы через LLM и дашборд аналитики.

Следствие для выбора: заказчик сначала выбирает идею по характеру сообщения о компании, затем уровень по бюджету. Переход между уровнями одной идеи после старта работ выполняется добавлением или снятием единиц масштабирования без переделки сделанного; переход между идеями означает новый проект.

Идея 2 наиболее устойчива по бюджету, поскольку стоимость определяется объёмом контента, а не арт-продакшеном. Идея 3 наименее устойчива: на уровне «Минимум» реализуется только фиксированный пролёт по секвенции кадров, а real-time 3D-мир начинается с уровня «Максимум». 4Общая платформа

Три идеи строятся на одном каркасе: React 19 с TypeScript на фронтенде, слой сцены (PixiJS или React Three Fiber в зависимости от идеи и уровня), backend на FastAPI для UGC, прогресса и проксирования запросов к LLM с лимитами, PostgreSQL, объектное хранилище и CDN для ассетов. Контент описывается JSON-манифестами, поэтому наполнение меняется без участия разработчиков. Развёртывание выполняется в Kubernetes с GitOps; для кампании достаточно двух реплик backend и автомасштабирования до восьми.

5Идея 1: День в Т-Банке

Рекомендуемая техническая база для уровней «Минимум» и «Средне» — pre-rendered изометрические сцены, полученные рендером 3D-моделей в слоях (фон, средний план, интерактивные объекты), поверх которых работает интерактивный слой на PixiJS с персонажем в виде spritesheet. Перемещение выполняется по графу точек. Уровень «Максимум» строится на real-time 3D-изометрии (React Three Fiber) со свободным перемещением, что соответствует формулировке «в духе симуляторов жизни» из презентации. Мини-игры реализуются как изолированные модули с единым контрактом (вход: контекст сцены, выход: результат и очки опыта), что позволяет добавлять их без изменения ядра.

5.3. Результат для заказчика по уровням

Минимум: 4 331 500 ₽, ориентировочно 10 недель

Заказчик получает работающий карьерный сайт с четырьмя отделами в изометрии, одним сквозным сценарием стажёра и четырьмя сотрудниками-персонажами, каждый из которых даёт задание и ведёт к вакансиям своего отдела. Сценарий проходится за 8–10 минут (оценка), после чего пользователь свободно возвращается в любой отдел. Мобильные пользователи получают тот же сценарий в виде вертикального маршрута без свободного перемещения. Тексты, реплики и вакансии редактируются через контент-файлы; правки выполняются исполнителем в период поддержки.

Средне: 5 881 500 ₽, ориентировочно 12 недель

Заказчик получает офис из шести отделов, аватар с настройкой, три типа мини-игр и механику «связи между отделами», при которой задача видимо перемещается из отдела в отдел. Рабочий день меняется от дня к вечеру по мере прохождения, что даёт вторую причину исследовать офис повторно. Мобильная версия работает с touch-управлением и полным набором сцен. Тексты, реплики, досье и вакансии редактируются заказчиком в административном интерфейсе без участия разработчиков.

Максимум: 7 910 000 ₽, ориентировочно 14 недель

Заказчик получает полную реализацию презентации: восемь отделов и зоны отдыха, свободное перемещение персонажа, четыре состояния дня с изменением наполнения офиса, пять типов мини-игр и сотрудников, отвечающих на свободные вопросы через LLM в границах согласованного контента. Прогресс сохраняется на сервере, пользователь возвращается по ссылке и продолжает день. Дополнительно заказчик получает дашборд аналитики: воронка от входа до перехода в вакансии по отделам, время в сценах, популярность мини-игр.

Состав передаваемых результатов на всех уровнях:

  • Сайт на домене заказчика с настройкой CDN и мониторингом на период кампании
  • Изометрические сцены отделов, персонажи и объекты в исходных файлах
  • Сценарий стажёра, реплики персонажей и досье сотрудников в согласованном виде
  • Контент-файлы или административный интерфейс (с уровня «Средне») для правок без разработки
  • Исходный код, документация по развёртыванию и по добавлению отдела
  • Аналитика событий: воронка до перехода в вакансии (дашборд на уровне «Максимум»)

6Идея 2: Дело «Ген роста»

Идея реализуется на React с собственным window manager (окна, папки, файловая система как JSON-манифест). Каждый файл описывается записью манифеста с типом (документ, фото, видео, чат, мини-игра) и признаком «содержит фрагмент», поэтому наполнение меняется контент-редактором без участия разработчика. Три мини-игры реализуются как отдельные модули; «поймать убегающий дедлайн» использует PixiJS. Мобильная версия на уровнях «Средне» и «Максимум» строится на метафоре смартфона Т-Банка с теми же манифестами, что снимает необходимость отдельного контента. Из трёх идей эта наиболее устойчива по бюджету: стоимость регулируется числом файлов и фрагментов, а не арт-продакшеном.

7Идея 3: Сайт-пролёт

Уровни отличаются способом рендеринга мира, и это главный фактор стоимости. Уровень «Минимум» реализуется как секвенция кадров, привязанная к скроллу (scroll-scrub), с HTML-наложениями для текстов и hotspot; такой подход даёт кинематографическое качество референса при предсказуемой производительности. Уровень «Средне» добавляет real-time объекты поверх pre-rendered фона с совмещённой камерой. Уровень «Максимум» реализуется как real-time 3D-мир на React Three Fiber с baked lightmaps, что даёт свободу интерактива и единый пайплайн ассетов. Референс persepolis.getty.edu по объёму 3D-продакшена превышает верхний уровень данной сметы; в презентации для заказчика это ограничение фиксируется явно.

9Сроки и команда

Сроки в документе являются ориентировочными и фиксируются в календарном плане договора после согласования объёма материалов заказчика. Срок отсчитывается от подписания до публикации при параллельной работе направлений: сценарий, дизайн и пилотная сцена выполняются одновременно, серия сцен производится пакетами, интеграция каждого пакета идёт параллельно с производством следующего.
